# ONVIF Browser для macOS

ONVIF Browser знаходить ONVIF-камери в локальній мережі, підключається до них з логіном і паролем і показує опис кожної камери:

- виробник, модель, прошивка, серійний номер;
- підтримувані версії ONVIF і профілі ONVIF (S/T/G…);
- сервіси (GetServices) з їхніми версіями та можливостями;
- повне дерево GetCapabilities і scopes;
- мережа: інтерфейси, MAC, IP, шлюз, DNS, NTP, порти HTTP/RTSP;
- медіа-профілі Media і Media2: кодек, роздільність, FPS, бітрейт, GOV, доступні опції енкодера, RTSP- і snapshot-посилання;
- дата й час пристрою та різниця з годинником Mac.

Звіт можна скопіювати (⇧⌘C) або зберегти в `.txt` (⌘S). Окремі рядки звіту копіюються через ⌘C.

Вимоги: macOS 10.15 або новіша, Swift 5.9 (Xcode 15.x). Без сторонніх залежностей.

## Збережені паролі

Якщо у вікні входу стоїть позначка «Запам'ятати пароль у зв'язці ключів» (вона ввімкнена за замовчуванням), логін і пароль після успішного входу зберігаються в зв'язці ключів macOS. Невдалі спроби входу не зберігаються. Під час наступного запуску програма сама підключається до камер, для яких є збережений пароль.

Пароль прив'язаний до ідентифікатора камери з WS-Discovery і до її адреси, тому зміна IP-адреси через DHCP його не губить. Камери, додані вручну, теж запам'ятовуються й з'являються в списку після перезапуску.

Меню «Пристрої» має пункти «Забути пароль пристрою», «Забути всі паролі…» і «Прибрати зі списку». Записи можна переглянути або видалити також у програмі «Зв'язка ключів»: шукайте «ONVIF Browser».

Застосунок підписаний ad-hoc, і після кожної нової збірки macOS вважає його іншою програмою. Тому при першому запуску нової збірки система може запитати дозвіл на доступ до зв'язки ключів. Натисніть «Дозволяти завжди».

## Збірка `.app`

```bash
cd ONVIFBrowser
chmod +x scripts/build_app.sh
./scripts/build_app.sh
```

Готовий застосунок з'явиться в `build/ONVIF Browser.app`.

Універсальна збірка (Intel + Apple Silicon):

```bash
ARCHS="x86_64 arm64" ./scripts/build_app.sh
```

Скрипт збирає release-версію, кладе в бандл `libswift_Concurrency.dylib` (без неї застосунок не запуститься на 10.15/11) і підписує все ad-hoc підписом.

## Іконка

Іконка лежить у `Resources/AppIcon.png` (1024×1024) і `Resources/AppIcon.icns`. Щоб поставити свою, замініть `AppIcon.png`: скрипт збірки сам перегенерує `.icns`. Якщо після збірки Finder показує стару іконку, перезапустіть Dock командою `killall Dock`.

## Запуск на інших Mac

Застосунок підписаний ad-hoc, тому Gatekeeper заблокує перший запуск. Відкрийте його через Finder: клацніть правою кнопкою → «Відкрити» → «Відкрити». Інший варіант — зняти карантин:

```bash
xattr -cr "/Applications/ONVIF Browser.app"
```

На macOS 15 і новіших при першому пошуку система запитає дозвіл на доступ до локальної мережі. Без нього пошук нічого не знайде.

## Розробка в Xcode

Відкрийте `Package.swift` в Xcode, оберіть схему `ONVIFBrowser` → My Mac → Run.

Тести (без камер, на зразках XML):

```bash
swift test
```

## Консольна утиліта для діагностики

```bash
swift run onvif-cli discover
```

```bash
swift run onvif-cli info 192.168.1.64 admin password
```

## Обмеження

- WS-Discovery працює тільки в межах одного широкомовного сегмента мережі. Камери в інших підмережах або VLAN додавайте вручну («Додати…»).
- Вбудованого відеоплеєра немає. Подвійний клік на RTSP-посиланні відкриває потік у VLC (з логіном і паролем), подвійний клік на Snapshot URI показує знімок з камери. Правий клік на рядку відкриває додаткові дії.
